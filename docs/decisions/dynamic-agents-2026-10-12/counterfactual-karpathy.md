**Strongest alternative:** Test bounded free-form composition directly against fixed routes and a curated catalog, rather than making catalog adoption a prerequisite. Generated task-specific instructions and team proposals could handle novel combinations that curators miss while avoiding catalog maintenance. This is a hypothesis, not a demonstrated capability. Keep authority, tools, budgets, evaluator ownership, and delivery gates controller-fixed; freeze each generated proposal before execution. Online routing learning is a separate intervention.

**Evidence that flips my decision:** On preregistered, lineage-disjoint future tasks, randomized comparisons show free-form composition exceeds both alternatives in independently accepted useful changes per total cost, including generation, review, failures, and maintenance. Hold provider/model versions fixed, separately vary team structure, and report unresolved-outcome bounds. Require a confidence bound above an economically justified margin, preserved recovery/quality, and measured protocol compliance. If the gain survives these controls within budget, prefer bounded generation over catalog-first B.
