### Essential Question
Which policy improves independently accepted changes per total cost/time without confusing confidence with evidence?

### Bias Diagnosis
**Facts (BRIEF, facts 2–3):** “High” confidence reflects recurrence, not calibration; three math-test attempts represent one failed workflow. A digest-mismatch allegation compared unlike digests; reviewer claims require independent adjudication.

**Inference:** Risks are anchoring on heuristic scores, overconfidence from repeated claims, and WYSIATI from observing only selected routes. Task difficulty, retries, workspace and model version confound provider comparisons.

### The Pre-Mortem
**Hypothesis:** Routing favors apparent winners assigned easier tasks; failed reviewer claims become negative memory, suppressing alternatives. Accepted-change counts rise while independent usefulness falls.

### Reference Class Forecast
**Unknowns:** Representative task-level base rates, calibrated probabilities, and comparative gains. Forty-five heterogeneous attempts cannot establish them. Expert heuristics can guide exploration without being calibrated estimates.

### De-Biasing Intervention
**Proposals:** Evaluation owner preregisters task strata, blinded acceptance, randomized A/B/C sandbox comparisons and holdouts. Count every assigned task, timeout, failure and abstention; include retry/review costs. Keep unresolved outcomes unknown, report coverage, and cluster uncertainty by task lineage.

Cold-start profiles inherit justified reference-class priors, otherwise remain unestimated; default to validated fixed routes. Abstain when eligibility is unknown. Council abstentions retain base weight: denominator 12.5, consensus threshold 25/3; confidence multipliers are heuristics.

### Verdict
**Inference:** A offers cheapest attribution but limited adaptation; B permits bounded specialization with evaluation overhead; C offers discovery but greatest confounding and evaluation-gaming exposure. Prefer A now; test B before promotion.
